# Placement Management System 🎓

An end-to-end full-stack web application designed to streamline student recruitment, application tracking, and placement workflows.

## 🚀 Features
* **Student & Admin Portals:** Role-based access for applicants and administrators.
* **Application Tracking:** Seamless job/internship application management.
* **Modern UI:** Clean and interactive user dashboard built with React.

## 🛠️ Tech Stack
* **Frontend:** React.js, CSS3 / HTML5
* **Backend:** Node.js, Express.js
* **Deployment:** Vercel
